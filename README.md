# 📊 Apple Products Revenue Dashboard

This project presents an **interactive Power BI dashboard** that analyzes Apple products' revenue performance across multiple dimensions including **region, product line, and sales channels**.  

## 🚀 Features
- Revenue analysis by **Region** (North America, Europe, Asia, etc.)
- Insights by **Product Line** (iPhone, iPad, MacBook, Services, Wearables)
- Channel contribution (Retail, E-commerce, Online, Apple Store, Offline)
- KPIs: **Revenue, Profit, ROI, Marketing Spend**
- Dynamic visuals for **quarterly analysis**

## 📂 Project Files
- `Apple_Revenue_Dashboard.pbix` → Power BI dashboard file  
- `Apple_RevenueDataset.csv` → Dataset used for analysis  
- `Dashboard.png` → Dashboard preview image
